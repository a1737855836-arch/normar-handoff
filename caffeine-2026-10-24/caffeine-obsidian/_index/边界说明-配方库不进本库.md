| 主题 | 归属 |
|------|------|
| 经典咖啡：浓缩 / 奶咖 / 过滤 | 配方库（小库线） |
| 现代特调：意式变奏 / 奶咖变奏 | 配方库 |
| 糖浆（配方一级） | 配方库（小库）；本知识库不收糖浆配方正文 |
| 杯型出品 / 手法笔记 / 季节空壳 | 不上树（COFFEE-003） |
| 拉花 / 奶泡 | `_素材/` 可选，不上主 MOC |
| 乙醇实验日志任何条目 | 另一产品，勿混 |
